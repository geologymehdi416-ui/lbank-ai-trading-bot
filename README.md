
# 🎯 LBank AI Futures Sniper Bot

ربات پایش و تحلیل بازار فیوچرز صرافی LBank با هدف شناسایی فرصت‌های معاملاتی باکیفیت و مدیریت ریسک.

## وضعیت پروژه

**Strategy:** Sniper Balanced  
**Exchange:** LBank Futures  
**Market:** USDT-Margined Futures  
**Entry Timeframe:** 1m  
**Higher Timeframes:** 4H / 1H / 15M / 5M  
**Minimum Net Risk/Reward:** 1.5  
**Order Execution:** Disabled

## اهداف ربات

- دریافت اطلاعات واقعی بازار Futures از LBank
- اعتبارسنجی قراردادهای معاملاتی
- بررسی روند تایم‌فریم‌های بالاتر
- شناسایی حمایت و مقاومت
- تحلیل ساختار بازار
- بررسی EMA، RSI و MACD
- بررسی حجم معاملات
- شناسایی نقاط ورود دقیق
- محاسبه حد ضرر و حد سود
- انتخاب حداکثر ۳ تا ۵ فرصت برتر
- ارسال گزارش به تلگرام

## استراتژی معاملاتی

### 1. تحلیل روند (HTF)

ابتدا روند بازار در تایم‌فریم‌های زیر بررسی می‌شود:

- 4H
- 1H

### 2. شناسایی ساختار بازار

موارد مورد بررسی:

- Higher High
- Higher Low
- Lower High
- Lower Low
- Break of Structure (BOS)
- Change of Character (CHoCH)
- Support and Resistance

### 3. بررسی اندیکاتورها

- EMA 20
- EMA 50
- EMA 200
- RSI 14
- MACD
- Volume

### 4. تایم‌فریم ورود

تایم‌فریم نهایی ورود:

**1 Minute**

ورود فقط پس از تأیید ساختار، مومنتوم و حجم مجاز خواهد بود.

### 5. مدیریت ریسک

- حداقل Net RR برابر 1.5
- محاسبه حد ضرر بر اساس ساختار بازار
- محاسبه تارگت بر اساس نسبت ریسک به بازده
- جلوگیری از ورود در شرایط نامناسب
- عدم استفاده از اهرم بالا بدون کنترل ریسک

## قوانین صدور سیگنال

ربات فقط در صورت تأیید تمام شرایط موردنیاز می‌تواند سیگنال صادر کند.

اگر داده کافی یا شرایط معتبر وجود نداشته باشد:

**NO TRADE — ورود نکن**

قیمت لحظه‌ای به‌تنهایی سیگنال معاملاتی محسوب نمی‌شود.

## منابع داده

منبع داده:

LBank Futures Public API

REST Base URL:

https://lbkperp.lbank.com/

WebSocket:

wss://lbkperpws.lbank.com/ws

فقط داده‌های Futures مجاز هستند.

استفاده از داده Spot به‌عنوان جایگزین داده Futures ممنوع است.
